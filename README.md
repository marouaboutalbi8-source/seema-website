# Seema · سيمة — website (v6 "Editions")

Bilingual (English/Arabic) static site for Seema, a Doha consultancy for strategy, identity and digital.

- `src/` — copy (`content.py`, `content_v6.py`), templates (`build.py`, `editions.py`), assets
- `dist/` — production build
- `dist-artifact/` — preview build

Build: `python3 src/build.py` (add `--artifact` for the preview build).

Photos are interim Unsplash images (see `src/credits.json`); case studies are placeholders.
